# Daily News Digest

Создание структурированных новостных сводок с фактчекингом.

## 🚨 ЧЕКЛИСТ (прочитать перед КАЖДОЙ сводкой)

- [ ] 5 обяз. категорий: 💰 экономика, 🔬 наука, 🤖 технологии, ⚔️ конфликты, ⚽ спорт
- [ ] Каждая новость: 1-2 источника в формате `📎 [Источник](url)`
- [ ] Запрещённые источники: ❌ interfax.ru, ria.ru, rt.com, tass.ru
- [ ] Спорт: конкретный результат/событие, а не расписание матчей
- [ ] Факт-чекинг: ОДНА строка внизу `📝 Факт-чекинг: ✅ N/M`
- [ ] **ЖЁСТКИЙ ЛИМИТ: ≤3500 символов** — сводка обязана влезть в одно сообщение Telegram
- [ ] **ЗАПРЕЩЕНЫ разделители**: никаких `───`, `---`, `***` — только пустая строка между блоками
- [ ] Максимум 1 новость на категорию (исключение: 2 если очень значимая)

## 🔒 КЕШИРОВАНИЕ ИСТОЧНИКОВ

Если существует `sources-cache.json` — загрузить и пропустить источники, проверенные менее 7 дней назад. После поиска обновить кеш.

## ⚠️ КРИТИЧЕСКИЕ ПРАВИЛА (обязательно перед каждым запуском)

1. **Ссылки — обязательны.** Каждый блок новостей должен содержать кликабельный URL. Сводка без ссылок = брак.
2. **Исключённые источники — ЗАПРЕЩЕНЫ:**
   - 🚫 **interfax.ru** — часто первый результат поиска, но ЗАПРЕЩЁН
   - 🚫 **ria.ru** — РИА Новости, ЗАПРЕЩЁН
   - 🚫 **rt.com / russian.rt.com** — Russia Today, ЗАПРЕЩЁН
   - 🚫 **tass.ru** — ТАСС, ЗАПРЕЩЁН
   
   НЕ использовать даже если новость есть только там. Лучше пропустить новость.
3. **5 обязательных категорий:** экономика, наука, технологии, конфликты, спорт — хотя бы по одной новости из каждой.

## ⚡ ПЕРЕД КАЖДЫМ ЗАПУСКОМ

**Обязательно перечитать этот файл целиком.** Даже если кажется, что помнишь правила — перечитай. Правила менялись, и старая версия из памяти ≠ актуальный скилл.

## Процесс

### 1. Поиск (БЫСТРЫЙ — максимум 5 запросов)

Выполнить **один** web_search на каждую из 5 обязательных категорий:
1. `"Россия экономика новости сегодня"` — 💰
2. `"наука технологии ИИ новости сегодня"` — 🔬 + 🤖 (объединить!)
3. `"закон законопроект регулирование Россия"` — приоритет при наличии
4. `"мировой конфликт геополитика сегодня"` — ⚔️
5. `"спорт результаты сегодня"` — ⚽

Параметры: `count: 8`, `freshness: "day"` (если пусто — `"week"`)

**Порядок в сводке**: экономика → законодательство (если есть) → наука → технологии → конфликты → спорт

### 2. Отбор (БЫСТРЫЙ)

Из результатов выбрать **1** новость на категорию. Критерий: самая значимая + есть конкретные цифры/факты.

**🚫 ЗАПРЕЩЁННЫЕ ИСТОЧНИКИ:** interfax.ru, ria.ru, rt.com, tass.ru — ИГНОРИРОВАТЬ.

**Приоритет источников:** vedomosti.ru, kommersant.ru, meduza.io, bbc.com > rbc.ru, lenta.ru, theguardian.com, reuters.com > остальные (кроме запрещённых).

### 3. Вывод (КОМПАКТНЫЙ)

Сразу писать сводку. Без промежуточных рассуждений.

## Ограничения

- **СТРОГО не более 5-6 блоков** (1 на категорию)
- **Каждая новость — 1-2 предложения максимум.** Без пространных объяснений.
- **Проверять даты** — новости должны быть свежими
- **Избегать кликбейта** — только факты
- Если обязательная категория не дала свежих результатов — расширить freshness до `"week"` или заменить на смежную тему
- **Приоритет новостей:** изменения законодательства > цифры/статистика > общие заявления
- **Итого ≤3500 символов** — если больше, сокращать описания

## ✅ Пример правильного блока новости

```
💰 Экономика

• Нефть Brent +8% до $116/барр — Иран закрыл Ормузский пролив. Россия получает ~$150 млн/день от роста.
  📎 [BBC](https://www.bbc.com/russian/articles/example)

⚽ Спорт

• Рыбакина выиграла WTA 500 в Штутгарте, обыграв Свёнтек 6:3, 6:4. Второй титул в сезоне.
  📎 [Sport24](https://sport24.ru/example)

📝 Факт-чекинг: ✅ 5/5
```

**Ключевые признаки хорошего блока:**
- Конкретные цифры (8%, $116, 6:3, 6:4)
- 1-2 источника на новость
- 1-2 предложения на новость — без воды
- Новость спорта — конкретный результат, а не «состоится матч»
- Факт-чекинг — одна строка в конце

## ❌ Анти-паттерны (НЕ делать)

- НЕ писать вступления перед сводкой (например, «создаю сводку», «готовлю новости», «вот главные новости сегодня!») — сразу к делу
- Выдавать сводку без ссылок, а добавлять их потом отдельным сообщением
- Использовать excluded-источники «за неимением лучших» — лучше пропустить новость
- Сливать несколько категорий в один блок (например, «наука и технологии»)
- Писать «подробнее по ссылке» вместо конкретных фактов в описании
- Начинать с «Вот главные новости сегодня!» или «Отличный вопрос!» — сразу к делу
- В блоке спорта просто перечислять предстоящие матчи — нужна конкретная новость (результат, рекорд, скандал, трансфер, чемпионство). Если nothing happened — хотя бы один значимый результат прошедшего матча

## Факт-чекинг

**Каждая новость ДО публикации**: найти 2 независимых источника, сравнить цифры/даты/имена. Неподтверждённые — не включать.

После сводки добавить **ОДНУ строку**: `📝 Факт-чекинг: ✅ N/M` (N — подтверждённых, M — всего). **Ничего больше.** Никаких объяснений, деталей, дат.
